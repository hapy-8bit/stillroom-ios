# 肋骨磁带孔边与带卷毛边修复

2026-11-08，One Tape iOS 0.4.0 / build70。

## 修改范围

肋骨壳体实际左右轮廓并非完全镜像。此前由左侧粗轮廓镜像生成的遮罩没有贴合右侧孔口，留下静态素材残片；带卷照片本身还包含塑料亮圈，旋转时形成白边。

- `OneTapeMouldGeometry.swift`：按壳体实际图像分别描出十二个平滑孔口，在资源像素与布局逻辑点的边界统一转换。
- `OneTapeMouldedCassette.swift`：仅肋骨款改为原生深色带卷纹理，去掉照片中的塑料圈；孔口增加固定的细暗边。静态纹理与外层旋转相位分开，沿用现有可取消视觉时钟与减少动效逻辑。
- 绘制测试增加肋骨款三个旋转角度的 3× 原生截图；真机流程覆盖播放、暂停和玻璃开合。选择卡沿用同一展示组件。

其他五款外壳及带卷素材未改。既有左右等大、同速规则、媒体时间、音频引擎、开屏和印花开关继续沿用。版本由69升至70。

## 保留的中间记录与边界

第一次放大照片裁切的模型检查虽通过，但放大图仍出现亮圈，最终改为原生带卷纹理并重新完成模型、构建和真机流程。第一次真机流程受 HUD 自动消失影响，未成功进入外观选择；仅调整测试导航同步后重跑通过，使用的冻结正常 App 未改。

归档期间共享源码继续调整了轴芯与黑色带卷的旋转边界，绘制测试也有后续修改；这些改动不归入冻结 build70 的验收。最终规则按用户后续要求另行构建、检查和交付，不将70包覆盖回较新的交付包。
