# 六款原创模塑的构件拆分与重做

本轮对应用户指出“六款原创磁带看着奇怪”，并强调仔细观察原版“模塑”组。仅修改 Stillroom iOS 的六款模塑及其印花对比色，保留现有磁带身份与偏好兼容。

## 观察依据

逐一查看本地原版 13 张原生 288 × 195 缩略图：骨架、古铜楔形、金色、象牙斜向、透明、橄榄、面板、纸张、银色、烟雾、落日、双弧、腰窗。原图与总览在 `Evidence/0.4.0/mould-structure-redesign-20261108/reference/`；只作为离线观察证据，没有将新增参考图放进产品资源。未操作原版 App；没有解锁或验收其付费完整材质和动效。

原版模塑的差异来自开窗与外壳如何遮住同一套机械构件，不能把浅色轮盘、黑色齿芯、带卷和外壳合成一张“长着两个孔的雕塑”。中央独立小窗只在部分款式存在，不属于全部模塑必须拥有的元素。

| 构件 | 必须保持的关系 | 可以变化的部分 |
| --- | --- | --- |
| 外框与内腔 | 稳定的磁带比例、边缘厚度与同一播放器卡座 | 外壳材质、颜色、浅台阶、接缝与局部支撑形态 |
| 两处驱动轴 | 共用同一对轴线；旋转齿芯与静止钢轴分层 | 外围轮盘的材质、孔纹和露出多少 |
| 磁带带卷 | 围绕驱动轴保持圆形，与外壳和轮盘有前后关系 | 开窗露出多少；本产品沿用此前左右等大、同速的选择 |
| 透明开窗 | 让人看见暗内腔、带卷、轮盘和轴芯，不能垫实心灰板 | 矩形、圆弧、斜切、分区、月牙，以及是否有独立中央窗 |
| 底部机构区 | 相同的梯形下沿、两圆两方的四处导向开孔与内部机构 | 表面色、浅筋线；不随美术任意变成大洞或挪动孔位 |
| 固定壳面与印字 | 旋转只进入驱动层，实际队列读数保持可读 | 品牌、插画、标签落点、支撑筋与窗口轮廓 |

## 六款落地

- 岩层：层叠的浅台阶围绕一体式横向开窗。
- 折面：斜切开窗与中央斜撑，以平面转折代替整面夸张多面体。
- 浮岛：两块独立开窗框与分区落字面。
- 肋骨：细直肋支撑大窗口，移除粗大放射状骨架。
- 流线：外壳与窗缘使用顺滑曲线，两处轴线保持水平。
- 月蚀：相对的月牙窗口与实体扇区，内部带卷仍是正圆，轴孔保持原位。

六款使用同一对既有播放器钢轴坐标，统一小尺寸黑色驱动齿芯、环形浅色轮盘、褐黑带卷和底部机构。静止钢轴与齿芯透明中心对齐；只旋转齿芯，等大带卷、轮缘与壳面固定。没有创建音频实例、传感器或第二媒体时钟。

摄影生成的六张旧壳面不再用于这六款的运行绘制；新壳面为 SwiftUI/Canvas 原生二维路径与光照。既有 `OneTapeClassicStill`、两张驱动层继续提供共用内部机构，原经典款与其他磁带的绘制入口保持。六款仍使用原有枚举身份，选择卡与主页共用几何和机构。缩略图与自定义预览省略会产生采样波纹的超细带卷圈纹及塑料颗粒，主页保留细节；该绘制质量差异不进入用户偏好或播放状态。深色款印花使用浅色墨，字区避开筋线；实体塑料不透出隐藏机构。品牌关闭时，实际总时长与曲数读数继续保留。

## 实现边界

几何以 576 × 376.33 逻辑点横向画布定义，统一旋转为播放器的竖向画布；不是设备像素布局，也不是制造 CAD。静态内腔、带卷、轮盘、壳面被独立合成，旋转相位只进入两个驱动视图。减少动效、暂停与后台继续沿用既有驱动相位规则。

完整构建、检查、设备与未验证项以 `Evidence/0.4.0/mould-structure-redesign-20261108/BUILD_RECEIPT.json` 为准。原版仅观察缩略图，本轮不宣称恢复了它的付费完整材质、真实透射或运动参数；音质、长时能耗和完整设备矩阵分别留作后续验收。
