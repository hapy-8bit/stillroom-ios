# 六款模塑共用统一印花

用户纠正了 build89 的理解：印花是独立且统一的；同一图案不能随磁带壳面重新构图。品牌文字可以按不同磁带分别呈现。

本轮撤掉 build89 的壳面专属插画落点、局部裁切、人物拆分、城市天际线节选、枝鸟重排及各壳光照取样。五种插画重新使用完整原资源，恢复与原有印花相同的画布尺寸、朝向和中心；六款模塑使用同一墨色、同一模板、同一机构避让遮罩。遮罩根据六款轮廓的共同范围及全部机构开口统一计算，不再因当前选择的壳面、透明边框或文字矩形而变化。

品牌文字与印花保持独立：无插画时保留六款各自的原生品牌与读数排版；有插画时将曲数、总时长放入印花下方的公共文字区，避免切开印花给不同位置的文字让位。实际队列数据、品牌与插画互斥设置、统一播放引擎、六款已确认摄影壳面、独立轴芯动画及当前组合预览均保留。

既有绘制 XCTest 中新增“同一印花跨六款像素不变”的回归断言，旧遮罩断言改为检查公共文字区；这些 XCTest 尚未执行。按用户此前“构建到手机，验证交给我”的要求，本轮只做源码约束、实际正常签名构建、严格签名校验、源码快照与保留数据安装，不运行模拟器、不启动 App、不作真机页面或音质验收。

构建、设备、安装版本及快照证据以 `Evidence/0.4.0/unified-print-layer-20261108/BUILD_RECEIPT.json` 为准。build89 的离线重排组合图与重排方案属于被用户纠正的历史，不代表当前效果。
