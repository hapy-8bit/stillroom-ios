# One Tape 六款模塑接续

> 2026-11-08 更新：六款壳面与机构已按原版模塑的构件关系重做为原生分层绘制。当前实现见 [构件拆分与重做](ONE_TAPE_MOULD_STRUCTURE_2026-11-08.md)；下文摄影生成壳面与旧坐标属于历史接入记录。

本轮由聊天「设计磁带样式并调整主标题字体」负责。用户已要求将六款设计加入 iOS 手机，后续这部分的改动继续由本聊天接续。工作范围是本独立 iOS 工程，不同步其他平台。

## 样式与资源

| 显示名称 | 持久化身份 | 结构 |
| --- | --- | --- |
| 岩层 | `strata` | 阶梯层叠、下沉圆窗 |
| 折面 | `facet` | 多面切削、六角开窗 |
| 浮岛 | `islands` | 双环浮岛、中央悬桥 |
| 肋骨 | `ribs` | 外露筋架、分段透窗 |
| 流线 | `stream` | 连续曲面、水滴双窗 |
| 月蚀 | `eclipse` | 偏心月环、相向月牙窗 |

入口是「自定义 → 磁带 → 模塑」，六款位于列表前部。原有 Codable 身份保留，新身份只扩展枚举。选中外观不替换播放队列，也不创建音频实例。

全部新壳面、轴心与磁带纹理来自本聊天生成的原始设计。应用中使用已去掉固定印字的表面、独立轴心样本和同组原始设计的磁带环纹理；没有让烘焙的 `43:28`、`12` 充当运行数据。来源与编辑提示在 `Evidence/0.4.0/moulded-shells-20261107/resource-inputs.json`，资源准备入口为 `Tools/prepare-moulded-shells.cjs`。提示中的自动透明抠图并非最终覆盖范围，原生轮廓负责裁切；素材转换先得到 RGB，再缩放，避免抠图透明区的 RGB 在重采样中变黑。

## 实现边界

- `OneTapeMouldGeometry.swift`：统一 576 × 376.33 **逻辑点**横向画布，资源归一化测量在这里转成逻辑坐标；壳面、卷轴、文字与印花遮罩共用一次 90° 变换。选择器缩略图共用同一壳面轮廓，裁掉生成画布边沿。外层沿用播放器的窗口缩放与安全区处理，不使用 iPhone 像素坐标布局。
- `OneTapeMouldedCassette.swift`：固定表面与独立卷轴分层。转角继续来自 `OneTapeReelMotion`，磁带半径使用当前队列进度；不维护另一个媒体时钟。照片暗部进一步约束开窗覆盖，防止近似路径涂到明亮的筋骨上。
- `OneTapeMouldedPrint`：主字使用已随包注册的 Instrument Serif Italic；总时长与曲数是独立功能读数，即使关闭品牌印字也保留。现有印花使用每款自己的可印区域，并为轴孔、走带区和读数留空。
- `OneTapeCassetteReadout.swift`：只读取当前完整队列及歌曲元数据。本地与服务器来源统一；队列中缺项、零／负／非有限或超出安全整数范围的时长均显示未知，不把已知子集合相加当总时长。重复曲目按队列出现次数计入。小时格式为 `h:mm:ss`，不足一小时为 `m:ss`，空队列显示 `--:--` 与 0 曲。
- `OneTapeRoot` 只投影权威 `PlayerStore` 数据，显示组件不访问持久化、选文件或音频服务。玻璃辅助功能读数包含当前样式、曲数与歌单总时长。

印花遮罩必须逐类相减。水滴路径与圆孔的绕向可能相反，先合成再相减会在重叠处抵消，重新露出可印区域；本轮测试发现并修正了这个问题。

## 后续修改顺序

修改某款外形时，一起核对该款的壳面轮廓、轴心位置／半径、开窗路径、文字落点和可印区域。不要只替换 PNG 而沿用另一款几何。资源像素只在准备／渲染边界使用；不要把图片采样尺寸写成屏幕尺寸。

继续运行 `node Tools/check-source.cjs`、实际 Xcode 构建和相关 XCTest。六款选择、开盖、冷恢复用 `OneTapeMouldedUITests`；队列总时长用 `OneTapeCassetteReadoutTests`；原生分层、独立转动、进度、印花遮罩和资源存在性用 `OneTapeMouldedRenderingTests`。六款循环使用独立外观 suite；正常预览流程选定岩层并将印花设为「无」，展示品牌字与新壳型，保留正常曲库、机身和屏幕选择。没有声称外观偏好文件字节不变。测试客户端会结束 App，交付时还要无测试参数正常启动。

开发团队继续只放在被忽略的 `Config/Signing.local.xcconfig`。手机测试构建可通过 `-xcconfig Config/Signing.local.xcconfig` 将相同本地签名配置用于测试目标，不把团队或证书硬写进工程。每次先重新确认 USB `wired`，保留数据覆盖安装。

## 验证与限制

模塑初次接入结果以 `Evidence/0.4.0/moulded-shells-20261107/BUILD_RECEIPT.json` 为准，不累计重复测试或把中途构建当交付版。早期遮罩失败与测试目标签名失败日志保留。后续 build59 的独立转轴积分、快转快门与切歌顺序核对，见 [卷轴与切歌接续](ONE_TAPE_REEL_MOTION_2026-11-07.md)。

这六款是二维摄影表面与原生运动层组成的视觉样式，不是实时三维网格。内部玻璃仍使用设计素材的灰色光照，尚未实现与任意机身颜色联动的真实透射。窗口／半径为本产品的视觉模型，不声称物理磁带机械参数精确复原。模型绘制检查、真实手机页面检查、实播音质与长期性能分别记录。
