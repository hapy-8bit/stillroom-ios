# 六款已确认收口模塑接入

> 当前印花规则已由用户纠正：同一印花跨六款统一，只有品牌文字按壳面变化。build89的印花重排已撤回；当前实现见 [统一印花说明](ONE_TAPE_UNIFIED_PRINT_LAYER_2026-11-08.md) 与 build90 凭据。以下保留为收口素材和89制作历史。

本轮按用户认可的完整六款造型接入 iOS：岩层、折面、浮岛、肋骨、流线、月蚀。沿用收口方案，将大部分带卷藏入壳内，保留小轴芯、观察缝与各自立体造型，给印花增加连续的不透明表面。用户要求“构建到手机，验证交给我”，本轮只做素材接入、源码约束检查、正常签名构建和保留数据覆盖安装，不运行 XCTest、模拟器、App 启动或页面检查。

## 资源与绘制

- 已确认设计：`output/imagegen/moulds-print-friendly-six-20261108/`。
- 无字生产图：`Evidence/0.4.0/approved-print-friendly-moulds-20261108/production-inputs/`。使用内置 imagegen 仅去除固定示意印字，保留壳面结构；完整提示、输入路径与源像素标定见同目录 `production-inputs.json`。
- 准备入口：`node Tools/prepare-approved-moulds.cjs`。对六张无字图统一裁切和等比归一化，并导出预览、两个驱动芯和两个静止钢轴样本。新资源使用 `OneTapeMould*Closed` 名称，历史素材保留。
- `OneTapeMouldGeometry` 将资源像素标定统一转成576 ×376.33逻辑点画布，包括壳体轮廓、两轴位置、实时文字落点和印花遮罩。不同设计保持其已确认图片的机位和造型，未将它们重新画成同一种平面外壳。
- 固定壳面与转动驱动芯分层，钢轴样本再覆盖到中心以保持高光静止；转角继续来自既有权威播放状态和视觉相位。没有创建新的音频实例或媒体时钟。
- 移除素材中固定的`43:28`、`12`及品牌字，由原生文字绘制真实总时长、曲数和可选品牌。素材预览不使用固定数字冒充运行读数。
- 印花不再套用经典磁带的整幅版式。小狗、毛毛虫按完整主体等比缩放到六款各自的安静实体落点；跷跷板的两个人物和支点分别编排；城市抽取连续天际线；植物抽取两组枝鸟并在枝叶边缘渐隐。人物与动物不进行非等比拉伸，经典磁带继续使用原有完整插画。
- 六款模塑的油墨使用各自摄影表面的明暗取样，不再叠加经典壳面的光照。印花仍避让轴芯、金属圈、小观察缝、实时数据和底部机构；浮岛保留透明边框。
- 磁带选择页此前始终关闭预览印花，印花选项也沿用经典磁带固定缩略图。现在磁带大预览保留实际印花，六款模塑的印花选项直接调用与播放器相同的壳面和印花组件；总时长与曲数通过原有权威数据传入，不另建状态或读取持久化。
- `print-layouts-recomposed.png` 是离线素材构图校准图，不是 App 截图，未包含原生最终安全遮罩、实时读数和玻璃。它只能说明素材编排，不能替代手机视觉验收。
